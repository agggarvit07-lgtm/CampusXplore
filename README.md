## 🌐 Live Website
[Visit CampusXplore](https://zingy-sorbet-db3c11.netlify.app/?floor=2&mode=Elevator)

## 1. Project Description

CampusXplore is a graph-based campus navigation system designed to help students, faculty members, and visitors find the shortest routes between different campus locations.

The project uses graph data structures and Dijkstra's shortest path algorithm to calculate optimal routes and distances. It provides a web-based interface that makes campus navigation easier and more accessible.

## 2. Problem Statement and Objectives

Finding classrooms, laboratories, departments, and other facilities across a large campus can be confusing, especially for new students and visitors.

CampusXplore aims to simplify campus navigation by providing:

- Easy searching of campus locations.
- Shortest-route calculation between source and destination.
- Distance calculation and route display.
- Multi-floor navigation using stairs and elevators.
- Accessibility support through stair avoidance.

CampusXplore is available through its web-based interface.

1. Open the CampusXplore website.
2. Select your source location.

4. View the calculated shortest route.

## 6. Major Features and Modules

1. **Location Management:** Stores campus location details.
2. **Graph Construction:** Connects campus locations using weighted edges.
3. **Source and Destination Search:** Allows users to select starting and ending locations.
4. **Shortest Distance Calculation:** Uses Dijkstra's algorithm to find the shortest path.
5. **Route Display:** Displays the calculated route and total distance.
6. **Multi-Floor Navigation:** Connects different floors using stairs and elevators.
7. **Accessibility Option:** Allows users to avoid stairs while finding a route.
8. **Web-Based Interface:** Provides an accessible interface for campus navigation.

## 7. Project Development and Implementation

The project was developed through the following stages:

1. Created the Location class for managing campus locations.
2. Developed the Graph class and implemented weighted connections.
3. Added source and destination searching functionality.
4. Implemented Dijkstra's algorithm using a priority queue.
5. Added route reconstruction and display functionality.
6. Integrated multi-floor navigation using stairs and elevators.
7. Implemented the accessibility option for stair avoidance.
8. Developed and integrated the web-based interface.
9. Deployed the website using Netlify.
